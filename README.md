# Mr. Big Beauty Ep01: project downloads

YO Skincare, Mr. Big Beauty Episode 01, every production file as of 17 Nov 2026: 50 zips, about 3.4 GB. No sign-in needed.

**How to download:** click any file name below to download it. Unzip every part of a group into the same folder: the folder paths inside each zip match the project, and each zip has a CONTENTS list.

- **frames-000 to frames-002** (and the start of frames-003) are the APPROVED frames, the only ones used for production.
- The rest of the frames parts are fix-pending frames and the do-not-use archive.
- **projects-000 to projects-036** are everything else: song master, scripts and plans, voices, mixes and stems, music, products, looks, storyboards, video clips and uploads.
